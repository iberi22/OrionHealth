# Contributing

Thank you for your interest in contributing to OrionHealth! We welcome contributions from the community.

## How to Contribute

- Open a GitHub Issue with clear reproduction steps. Include expected vs actual behavior, device model, and Android version.
- Start a GitHub Discussion before implementing. We value community input for roadmap planning.

## Code Style

- Follow the official Dart style guide.
- Use Conventional Commits for commit messages.
- Keep PRs focused on a single feature or fix.

## Testing

All new features must include appropriate tests. Run the test suite before submitting your PR:

```bash
flutter test
```
