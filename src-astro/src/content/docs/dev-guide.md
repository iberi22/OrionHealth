# Developer Guide

Everything you need to set up your development environment and start contributing to OrionHealth.

## Prerequisites

Make sure you have the following tools installed before setting up OrionHealth locally:
- Flutter SDK (stable channel)
- Dart SDK
- Android Studio / Xcode
- Git

## First-time setup

1. Clone the repository:
```bash
git clone https://github.com/iberi22/OrionHealth.git
cd OrionHealth
```

2. Install dependencies: `flutter pub get`
3. Run the app: `flutter run`
