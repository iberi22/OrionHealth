## e2e-android nightly failure (red 2026-09-28 .. 2026-10-02)

Root causes (run 36994224024, "0 tests passed, 7 failed"):

1. `integration_test/app_test.dart` created `integration_test/screenshots` in `main()`;
   on the emulator that path is a read-only filesystem (errno 30), so the file failed
   to load. It also relies on `matchesGoldenFile` (host-only), so the smoke job now runs
   only `critical_flows_e2e_test.dart`.
2. `critical_flows_e2e_test.dart` test 1 never set birth date or sex, so
   `OnboardingCubit.nextStep()` rejected the basic-info step and "Condiciones de Salud"
   was never shown. The test now picks a date and "Masculino".
3. Tests 2-7 failed with `IsarError: Instance has already been opened` because
   `getIt.reset()` does not close Isar. A `_resetDi()` helper now closes it first.

Fixes are untested on a device/emulator; the next nightly run is the check. Tests 4-7
may have further independent failures hidden behind the cascade.
