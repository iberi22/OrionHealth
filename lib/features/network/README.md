# Network Feature

## Propósito
Gestión de la red de nodos de OrionHealth: gobernanza descentralizada, incentivos, y monitoreo de salud de la red P2P. Permite la conexión segura entre dispositivos para compartir datos de salud.

## Sub-features
- **governance**: Reglas y consenso de la red.
- **incentives**: Sistema de recompensas por participación.
- **network_health**: Monitoreo del estado de la red.

## Capas
- **Domain**: Entidades de red, nodos, gobernanza e incentivos.
- **Infrastructure**: Comunicación P2P, sincronización.
- ⚠️ **Faltan**: capas application y presentation para network_health.

## Estado
- **Tests**: 32 unit tests.
- **Arquitectura**: Parcial (3/4 capas) — falta application/presentation para network_health.
