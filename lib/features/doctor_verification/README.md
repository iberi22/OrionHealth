# Doctor Verification Feature

## Propósito
Verificación y autenticación de profesionales de la salud. Permite a los usuarios confirmar la identidad y credenciales de sus médicos.

## Capas
- **Domain**: Entidades de doctor/verificación, repositorio abstracto, casos de uso.
- **Application**: Cubit para estado de verificación.
- **Infrastructure**: Datasources de verificación, repositorio de implementación.
- **Presentation**: UI de verificación y perfiles de doctores.

## Estado
- **Tests**: 36 unit tests, 4 golden tests.
- **Arquitectura**: Clean architecture completa (4 capas).
