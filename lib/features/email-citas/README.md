# Email-Citas Feature

## Propósito
Gestión de citas médicas vía email. Permite enviar, recibir y procesar confirmaciones de citas a través de correo electrónico.

## Capas
- **Domain**: Entidades de email-cita, repositorio, casos de uso.
- **Application**: Cubit para estado de la bandeja de citas por email.
- **Infrastructure**: Datasources de email, repositorio de implementación.
- **Presentation**: UI para visualizar citas recibidas por email.

## Estado
- **Tests**: 15 unit tests.
- **Arquitectura**: Clean architecture completa (4 capas).
