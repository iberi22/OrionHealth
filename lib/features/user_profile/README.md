# User Profile Feature

## Propósito
Gestión del perfil del usuario: información personal, foto, preferencias de salud, contactos de emergencia y configuración de privacidad.

## Capas
- **Domain**: Entidades de perfil de usuario, repositorio abstracto, casos de uso.
- **Application**: Cubit para estado del perfil y edición.
- **Infrastructure**: Datasources de perfil, repositorio de implementación.
- **Presentation**: UI de perfil con formularios y vista de información.

## Estado
- **Tests**: 12 unit tests.
- **Arquitectura**: Clean architecture completa (4 capas).
