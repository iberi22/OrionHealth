# Home Feature

## Propósito
Pantalla de inicio de OrionHealth. Muestra bienvenida, acceso rápido a funcionalidades principales y estado general del perfil de salud del usuario.

## Capas
- **Domain**: Entidades del home, repositorio abstracto, casos de uso.
- **Application**: Cubit para estado de la pantalla de inicio.
- **Infrastructure**: Datasources y repositorio de datos agregados.
- **Presentation**: UI del home con acceso rápido y resumen.

## Estado
- **Tests**: 19 unit tests.
- **Arquitectura**: Clean architecture completa (4 capas).
