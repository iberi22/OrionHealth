# Medical Research Feature

## Propósito
Herramienta de búsqueda y referencia de información médica. Permite consultar estándares médicos, investigaciones y literatura clínica relevante.

## Capas
- **Domain**: Entidades de investigación médica, repositorio abstracto, casos de uso.
- **Application**: Cubit para búsqueda y estado de resultados.
- **Infrastructure**: Integración con APIs de literatura médica, repositorio.
- **Presentation**: UI de búsqueda y visualización de resultados.

## Estado
- **Tests**: 24 unit tests, 1 golden test.
- **Arquitectura**: Clean architecture completa (4 capas).
